# Gock

Gock is my silly discord bot, you can invite the official bot to your server [here](https://discord.com/oauth2/authorize?client_id=1388996577065959524)

## Features

### Chat triggers

"im ____" -> "hi ____ im gock"
"@gock is this true?" -> "yeh" - add a zero width joiner and it says "nuh" instead

### Math

Send a basic math equation in chat and gock will tell you the answer
Supported operations: addition, subtraction, multiplication, exponentiation, factorials
Uses a custom integer type when results are larger than a u64

### Commands

/setchances imchance, mathchance - adjust the chance of chat triggers activating if they get annoying
/factorial - calculate the factorial of a number
/power - calculate a^b
